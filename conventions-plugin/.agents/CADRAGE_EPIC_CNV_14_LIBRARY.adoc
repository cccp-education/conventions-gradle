== 1. Contexte — ce que CNV-13 n'a pas couvert

L'EPIC CNV-13 a rendu l'adoption **mesurable** (`auditConventionsAdoption`) et
a migré les builds **consommateurs** (publics et privés MVP0). Il reste un
angle mort : les **contrats N0** de `workspace-bom` (MEMPHIS) n'appliquent que
la convention `lint`. Mesure S-029 :

|===
| Module N0 | Lignes | Conventions | Duplication restante

| `agent-contracts` | 211 | `lint` | plugins java-library/kotlin/maven-publish, toolchain 25, repositories, deps JUnit, `cucumberTest`, test logging, POM, signing
| `codebase-contracts` | 86 | `lint` | idem (sans cucumber)
| `i18n-contracts` | 130 | `lint` | idem + `cucumberTest` + relocation XML
| `llm-pool-contracts` | 85 | `lint` | idem

Total ≈ **1 047 lignes** dont une grande partie est structurellement identique
(bloc `plugins`, `group`/`version`, `jvmToolchain(25)`, `repositories`,
configuration `Test`, `java { withSourcesJab/withJavadocJar }`, POM, signing).
La convention `gradle-plugin` ne convient pas : elle applique
`java-gradle-plugin` (métadonnées de plugin) alors qu'un contrat N0 est une
**bibliothèque** consommée par `implementation(...)`.

== 2. Décisions d'architecture

. **Nouveau plugin `education.cccp.build.library`** — applique `java-library`,
   `maven-publish` et `org.jetbrains.kotlin.jvm` ; configure Java 25,
   `withSourcesJar`/`withJavadocJar`, toolchain 25, repositories, cache de
   build, tâches `Test` (JUnit Platform + logging), dépendances de test
   (`workspace-bom` + JUnit) et les gardes (`verifyGradleWrapper`,
   `auditConventionsAdoption`).
. **Factorisation à 2 consommateurs** (amendement S-195) — la configuration
   JVM commune à `gradle-plugin` et `library` est extraite dans
   `JvmProjectConventions` (objet interne, non contractuel). Aucun changement
   de comportement pour `gradle-plugin`.
. **Frontière publishing** — `library` **n'inclut pas** le POM/signing : le
   consommateur applique `education.cccp.build.publishing` (identité
   paramétrable CNV-13.1). Un contrat N0 peut ainsi publier sous Apache-2.0
   sans dupliquer le bloc `publishing { }` / `signing { }`.
. **Aucun contrat N0 n'est modifié dans cette session** — l'adoption appartient
   à la session MEMPHIS (un seul sessionneur par borough). CNV-14 est donc
   découpée : US-1 (plugin + preuves) ici, US-2 (release 0.0.12) et US-3
   (adoption des 9 modules N0) ensuite.
. **Local = Build, Tests = CI** — compilation + `validatePlugins` + `assemble`
   en local ; `test`/`functionalTest`/`cucumberTest` exclusivement en CI après
   push.
