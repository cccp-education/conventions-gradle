=== `youtube-auth-plugin v0.0.4` (N1)

La correction US-4 (session navigateur isolée, profil Chromium sans cookie) est
publiée sur JitPack.

* Le tag `v0.0.3` a échoué : l'installation SDKMAN `25.0.5.0+8-tem` a été
  refusée deux fois par le CDN (« Download has failed »). Le `before_install`
  du `jitpack.yml` utilise désormais le candidat **`25-open`** (celui qui
  fonctionne sur l'image JitPack) avec un retry et un garde `java -version`.
* Nouveau tag `v0.0.4` (commit `34f618c`), build **ok** :
  * `com.github.cccp-education.video-kernel-gradle:youtube-auth-plugin:v0.0.4`
  * marker `education.cccp.video.auth.gradle.plugin:v0.0.4`

`v0.0.3` reste visible comme échec (JitPack) ; `v0.0.4` est la version utile.

== 3. Correctif `jitpack.yml` (video-kernel)

[source,yaml]
----
before_install:
  - sdk install java 25-open || (sleep 10 && sdk install java 25-open)
  - sdk use java 25-open
  - java -version 2>&1 | grep -q 'version "25'
install:
  - if [ "${VERSION#v}" = "0.7.1" ] || [ "${VERSION#v}" = "0.7.0" ]; then ./video-kernel-plugin/gradlew -p video-kernel-plugin publishToMavenLocal -Pversion="${VERSION#v}"; fi
  - if [ "${VERSION#v}" = "0.0.4" ]; then ./youtube-auth-plugin/gradlew -p youtube-auth-plugin publishToMavenLocal -Pversion="${VERSION#v}"; fi
----

Le versioning est désormais forcé depuis le tag (`-Pversion`), donc le
POM/module metadata correspond à la coordonnée JitPack.
