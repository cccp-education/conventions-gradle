= Session 052 — GBL-014-5 : `verifyChannel` dans toutes les conventions
:date: 2026-11-15
:scope: conventions-plugin — fermeture du trou de gate `.cucumber`/`.library`, preuve container-provision
:statut: ✅ CI VERTE (`654a55d` run `43678844589`, `95a8387` run `43679188725`) + RELEASE JITPACK `v0.0.20`

== Contexte

Le rollout S-229/051 laissait un trou de gate : `verifyChannel` n'était
enregistré que par `.lint` et `.publishing`. Un build n'appliquant que
`.cucumber` (le consommateur container-provision) ou `.library` n'avait **aucun**
contrôle de cohérence de canal. Décision : l'enregistrer depuis **toutes** les
conventions.

== Design

`ChannelVerificationTask.register(project)` est appelé depuis chaque
`*ConventionsPlugin` du module :

[cols="2,3", options="header"]
|===
| Convention | Appel

| `.gradle-plugin` | `GradlePluginConventionsPlugin.apply`
| `.library` | `LibraryConventionsPlugin.apply`
| `.cucumber` | `CucumberConventionsPlugin.apply`
| `.functional-test` | `FunctionalTestConventionsPlugin.apply`
| `.kover` | `KoverConventionsPlugin.apply`
| `.lint` | `LintConventionsPlugin.apply` (déjà, S-051)
| `.logback-exclusion` | `LogbackExclusionConventionsPlugin.apply`
| `.publishing` | `PublishingConventionsPlugin.apply` (déjà, S-050)
|===

`register` reste **idempotent** (`tasks.names.contains`) : un build appliquant
plusieurs conventions n'a qu'une tâche. La sémantique de transition est
**conservée** : `check` dépend de `verifyChannel` **seulement** si `-Pchannel`
est explicite (aucun test/CI existant n'est activé par surprise).

=== Écart mesuré — répertoire de la preuve

Le trou était décrit comme « `container-provision-plugin` applique uniquement
`.cucumber` ». En réalité, le `.cucumber` est appliqué par le **build racine**
(`container-provision-gradle/build.gradle.kts`) ; `container-provision-plugin/`
est un **build autonome** (article 0124) qui n'applique **aucune** convention.
La preuve est donc faite à la racine (le seul build `.cucumber` du dépôt) ;
`verifyChannel` reste volontairement absent du sous-build plugin tant qu'il
n'adopte pas une convention (décision de rollout US-5, pas ajoutée ici pour ne
pas modifier son build).
