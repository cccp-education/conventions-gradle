== 2. CNV-13.6 — Gradle 9.8.2 : version unique, gardée en CI

Demande pilote : « veille à ce que tout le workspace soit sous Gradle 9.8.2,
centralise cette configuration, que ce soit le système de maintien dans les
workflows GitHub Actions ».

**Centralisation (une seule source de vérité)** :

* `conventions-plugin/gradle/libs.versions.toml` → `[versions].gradle = "9.8.2"` ;
* matérialisée en ressource `build/gradle-version.properties`
  (`generateGradleVersionInfo`) ;
* domaine pur `GradleWrapperVersion` (lecture, parsing `bin`/`all`, verdict,
  message de dérive) — anti-drift identique à `WorkspaceBom` ;
* **`GradleWrapperVerification`** enregistre la tâche `verifyGradleWrapper`
  et la câble à `check`, depuis **`gradle-plugin`** (15 consommateurs) **et
  `lint`** (28 consommateurs, le plus répandu) → **tout CI qui lance `check`
  échoue sur une dérive**, sans câblage supplémentaire ;
* un projet **sans** wrapper (fixtures TestKit, module `includeBuild`) passe
  avec un warning (contrat « plugin does not fail on check » préservé).

**Système de maintien CI** :

* `.github/actions/verify-gradle-wrapper/action.yml` — action composite
  réutilisable (`uses: cccp-education/conventions-gradle/.github/actions/verify-gradle-wrapper@main`),
  input `expected-version` (défaut `9.8.2`), `wrapper-path` ;
  implémentation **sans pipe** (leçon SIGPIPE S-318) ;
* utilisée par le workflow de ce dépôt (`wrapper-path: conventions-plugin/...`).

**Bump effectif** : **101/101** `gradle-wrapper.properties` du workspace en
`9.8.2` (95 mis à jour depuis `9.8.1`/`9.8.0`, 6 déjà à jour).

**Publication** : `conventions-plugin 0.0.10` — CI verte `41729277381`
(182 PASSED), **Maven Central** bundle `6a3b7052-e516-4377-ad5a-a08dab36a4dc`
(AUTOMATIC), Plugin Portal soumis.

**Preuves** : 8 UT `GradleWrapperVersionTest`, 3 FT TestKit (aligné, dérive,
câblage `check`), 2 scénarios BDD ; dogfood réel sur `academy-plugin` —
`verifyGradleWrapper` VERT en 9.8.2, **rouge** sur dérive forcée 9.8.1
(message nommant les deux versions), wrapper restauré.
