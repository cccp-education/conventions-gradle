== Mission

Exécuter **CNV-16.1** sur feu vert pilote (« c'est parti », option B validée) :
préparer le dépôt pour un build JitPack, **sans** pousser de tag ni publier.

== 1. Livré

=== `jitpack.yml` (racine du dépôt)

* `before_install` : `sdk install java 25.0.5.0+8-tem` + `sdk use java 25.0.5.0+8-tem`
  (JitPack démarre en JDK 8) ;
* `install` : `./gradlew -p conventions-plugin publishToMavenLocal
  -Pversion="${VERSION#v}" -x test -x functionalTest -x cucumberTest`
  (le vrai build est le **sous-build** ; la version vient du tag) ;
* `env: CI: "true"` (pas de GPG chez JitPack).

=== Version dérivée du tag (`conventions-plugin/build.gradle.kts`)

* `version = providers.gradleProperty("version").getOrElse("0.0.14")` ;
* **garde** : si `JITPACK=true` et `-Pversion` absent → `error(...)` explicite
  (l'artefact ne peut pas diverger de son tag) ;
* fallback local/CI inchangé (`0.0.14`).

=== Signature conditionnelle (verrou réel découvert)

`com.gradle.plugin-publish` **2.2.1** active automatiquement la signature dès
que le plugin `signing` est appliqué (`enableSigning`), **même avec
`CI=true`** — la simulation a produit 13 `.asc` et 9 tâches `sign*` sur JitPack
(pourtant sans clé). Correctif : `signing` n'est **plus** dans le bloc
`plugins {}` ; il est appliqué dynamiquement **uniquement** si
`!jitpackBuild && (CCCP_PUBLISH=true || CI != true) && version non SNAPSHOT`.
La matrice est vérifiée :

[cols="3,2"]
|===
| Contexte | Tâches `sign*`
| local (`CI`/`JITPACK` absents) | **9** (signe)
| CI test (`CI=true`) | **0**
| CI release (`CI=true CCCP_PUBLISH=true`) | **9** (signe)
| JitPack (`CI=true JITPACK=true -Pversion`) | **0**
|===

== 2. Preuves locales (Local = Build)

* `compileKotlin` + `compileTestKotlin` + `compileFunctionalTestKotlin` VERT.
* `assemble` + `validatePlugins` VERT.
* Garde : `JITPACK=true` sans `-Pversion` → échec avec message explicite
  (`exit=1`) ; avec `-Pversion=0.0.15` → `BUILD SUCCESSFUL`.
* Override : `properties -Pversion=9.9.9` → `version: 9.9.9`.
* **Simulation exacte de l'`install`** :
  `CI=true JITPACK=true VERSION=v0.0.15-probe2 … publishToMavenLocal
  -Pversion="${VERSION#v}"` → `BUILD SUCCESSFUL`, POM `0.0.15-probe2`,
  **9 POM** (module + 8 markers), **0 tâche `sign*`**, **0 `.asc`**.

Aucun test local exécuté ; aucune publication Central/Portal ; aucun tag
poussé. Deux versions de sonde (`0.0.15-probe`, `-probe2`) subsistent dans
`~/.m2` (sans effet sur le build).
