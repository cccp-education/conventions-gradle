== Architecture — TestDependencies.kt (DDD)

Nouveau fichier : `src/main/kotlin/build/TestDependencies.kt`

Single responsibility : centraliser l'ajout de deps test (junit, cucumber, platform
BOM) avec fallback hardcoded quand le catalogue `libs` du projet consommateur est
absent. Élimine la duplication des versions divergentes entre boroughs.

Cascade de résolution : catalogue `libs` du projet consommateur > fallback hardcoded.

API publique :
* `TestDependencies.libs(project)` — récupère le catalogue `libs` (null-safe)
* `TestDependencies.addPlatformBom(project, config)` — ajoute `workspace-bom:0.0.4` en platform
* `TestDependencies.addFromCatalog(project, libs, config, key, fallback)` — lit catalogue, fallback hardcoded
* `TestDependencies.addCucumberDeps(project, config)` — 5 deps cucumber (fallback 7.34.3 / 1.14.3)
* `TestDependencies.addJunitDeps(project, implConfig, runtimeConfig)` — 5 deps junit (fallback 5.12.2 / 1.14.3 / 3.27.7)

Constantes :
* `WORKSPACE_BOM_COORDINATES = "education.cccp:workspace-bom:0.0.4"`
* `CUCUMBER_FALLBACKS` : Map<String, String> (5 entrées)
* `JUNIT_FALLBACKS` : Map<String, String> (5 entrées)

Consommateurs :
* `CucumberConventionsPlugin` (US-CN-7.1) → `addCucumberDeps` + `addPlatformBom` sur `testImplementation`
* `GradlePluginConventionsPlugin` (US-CN-7.2) → `addJunitDeps` + `addPlatformBom` sur `testImplementation` + `testRuntimeOnly`
* `FunctionalTestConventionsPlugin` (refactor) → `addPlatformBom` + `addFromCatalog` (suppression helpers locaux)
