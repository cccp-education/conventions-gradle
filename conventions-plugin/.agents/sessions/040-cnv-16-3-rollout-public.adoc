== Mission

Demande pilote : « sur tous les projets dans `foundry/public/` ». Câbler le
shim JitPack (`education.cccp.build.*` → module `conventions-plugin`) dans
tous les builds Gradle publics et prouver la CI verte. Décision de rollout
(US-6) : le canal secondaire JitPack devient le **résolveur par défaut** des
conventions pour les builds publics.

== 1. Périmètre

**27 dépôts**, **55 `settings.gradle.kts`** modifiés : le `settings` racine
de chaque dépôt **et** les sous-builds autonomes (`<projet>/<plugin>/`,
`academy/dogfood`, `conventions-plugin`, `video-kernel-plugin`,
`youtube-auth-plugin`, les **9 contrats** de `workspace-bom`). Les projets
sans `pluginManagement` (ex. `notebook`, `newpipe/doc`) et les non-Gradle
(`office-template`, `intellij-plugins`, `dashboard-flow`) sont hors périmètre.

=== Snippet appliqué (identique partout)

[source,kotlin]
----
// CNV-16 — JitPack mirror for the education.cccp.build.* conventions
// (bypasses Sonatype / Gradle Plugin Portal). The JitPack tag is pinned while
// the canonical plugin declarations may stay on the released version.
pluginManagement.repositories.maven("https://jitpack.io")
pluginManagement.resolutionStrategy.eachPlugin {
    if (requested.id.id.startsWith("education.cccp.build.")) {
        useModule("com.github.cccp-education.conventions-gradle:conventions-plugin:0.0.15")
    }
}
----

* Le **tag JitPack est épinglé `0.0.15`** ; les déclarations canoniques
  restent `0.0.14` (Central/Portal) — les builds publics résolvent donc les
  conventions depuis JitPack, sans Sonatype ni Portal.
* L'audit `auditConventionsAdoption -Pstrict` signalerait `Obsolete`
  (pins 0.0.14 vs plugin 0.0.15) ; il n'est **pas** câblé à `check` (aucun
  workflow ne l'exécute en strict). À réaligner lors du prochain bump
  coordonné.
