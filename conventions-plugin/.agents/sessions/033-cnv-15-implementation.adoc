== 1. CNV-15.1 — auto-publication `publishing`

* `PublishingConventionsExtension.createMavenPublication` (défaut `false`,
  backward compatible) ;
* `configurePublishing` crée la publication `maven` depuis `components["java"]`
  **si aucune `MavenPublication` n'existe** — sinon comportement inchangé ;
* preuves : FT `plugin creates the maven publication when opted in` +
  `plugin does not create a publication by default` ; BDD
  `publishing-conventions.feature` scénario « creates the maven publication
  when opted in » ;
* **9 contrats N0 migrés** : `createMavenPublication = true` + suppression du
  bloc `publishing { publications { create<MavenPublication>("maven") { … } } }`
  (workspace-bom commit `cfbbf8c`, **−104/+41 lignes**).

== 2. CNV-15.2 — `DetektCompatibility`

* objet pur `DetektCompatibility` : `supports(javaVersion)` vrai pour un
  majeur `1..22`, faux pour `25`/`26`/`unknown` (le `startsWith("25")` codé
  en dur disparaît) ;
* `LintConventionsPlugin` utilise `supports` + `diagnostic` ;
* preuves : `DetektCompatibilityTest` **7 UT** + BDD
  `lint-conventions.feature` Scenario Outline (21/22/25/26/unknown).
