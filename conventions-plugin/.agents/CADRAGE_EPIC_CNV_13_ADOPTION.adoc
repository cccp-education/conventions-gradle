== 2. Décisions d'architecture

. **CNV-13 = EPIC d'adoption**, pas de nouveaux plugins : le code des
  conventions est stable, le reste est du déploiement.
. **`publishing` paramétrable** : identité POM (licence + developer) et
  `website`/`vcsUrl` surchargeables via `publishingConventions { … }`, défauts
  cccp inchangés (backward compatible). Indispensable pour les builds
  **propriétaires** (payment-scaffold est CSS, pas Apache-2.0).
. **Adoption par lots**, un borough par session :
  * **L1 — payment-scaffold** (16 modules, gain mécanique) ✅ S-024 ;
  * **L2 — privés MVP0** : training (cœur), workspace, waiter, quizz ;
  * **L3 — rollout public** `0.0.9` + catalogue MEMPHIS + propagation Portal ;
  * **L4 — outillage** : garde cross-borough de pin/compilation (modèle
    `verifyCrossBoroughPins` MEMPHIS), réévaluation `kover`/`logback-exclusion`.
. **Pin BOM de test réaligné** sur la dernière version publiée (0.0.59 →
  0.0.124) : le platform injecté ne doit jamais être périmé.
. **Tests = CI** : compilation + `validatePlugins` en local ; `test`/
  `functionalTest`/`cucumberTest` exclusivement en CI après push.

=== CNV-13.6 — détail (version Gradle)

* **Source unique** : `conventions-plugin/gradle/libs.versions.toml`
  `[versions].gradle = "9.8.2"` → ressource `build/gradle-version.properties`.
* **Domaine pur** `GradleWrapperVersion` (parsing `bin`/`all`, verdict,
  diagnostic) — 8 UT.
* **Garde en CI** : `verifyGradleWrapper` enregistrée par `gradle-plugin` et
  `lint`, câblée à `check` → tout CI qui lance `check` échoue sur une dérive
  (3 FT TestKit + 2 BDD). Un projet sans wrapper passe avec un warning.
* **Action composite réutilisable** :
  `.github/actions/verify-gradle-wrapper/action.yml` (défaut `9.8.2`,
  `wrapper-path` configurable, sans pipe → pas de SIGPIPE).
* **Bump** : 101/101 wrappers du workspace en 9.8.2 ; release **0.0.10**.

== 4. Definition of Done (EPIC)

* Tous les builds Gradle du workspace (publics **et** privés) appliquent les
  conventions ; zéro bloc POM/signing/test dupliqué.
* `conventions-plugin` publié, catalogue MEMPHIS aligné, racine dogfood alignée.
* Une **garde** interdit un pin de consommateur supérieur à la version publiée
  et compile la matrice des consommateurs.
* ADR-001 réécrit (modèle binaire publié).
* Aucune régression : CI verte sur chaque dépôt touché.
