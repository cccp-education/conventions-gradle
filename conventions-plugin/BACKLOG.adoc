== ✅ TERMINE — CNV-7 : Centralisation des dépendances de test

_Dépendances JUnit + Cucumber gérées par les convention plugins — élimine la duplication et les bugs de version dans les catalogues locaux des boroughs._

*Priorité* : P1 — débloque US-I18N-6 plantuml (tests `:test` cassés par `junit-platform-params = "6.0.3"` dans catalogue local)
*Charge estimée* : ~8 pts (~2 sessions)
*Dépend de* : CNV-4 (CucumberConventionsPlugin existe), CNV-3 (FunctionalTestConventionsPlugin existe)
*Statut* : ✅ TERMINÉ (session 010, 2026-07-05)

=== Contexte

Découvert session plantuml 158 : `junit-platform-params = "6.0.3"` (version inexistante)
dans `plantuml-plugin/gradle/libs.versions.toml` casse l'exécution des tests
(`NoSuchMethodError: CollectionUtils.toUnmodifiableList()`).

Racine : les convention plugins ne géraient **pas** les dépendances de test.
Tous les boroughs (bakery, capsule, plantuml…) dupliquaient
`testImplementation(kotlin("test-junit5"))`, `junit-platform-launcher`,
`libs.bundles.cucumber`, `junit-platform-params` dans leur `build.gradle.kts`
local avec des versions hardcodées dans leur catalogue — d'où les divergences
et bugs.

=== Architecture cible (RÉALISÉE)

* `GradlePluginConventionsPlugin` (via `TestDependencies.addJunitDeps`) :
  - `testImplementation` : `kotlin("test-junit5")`, `junit-jupiter` (fallback `5.12.2`),
    `junit-platform-params` (fallback `5.12.2`), `assertj-core` (fallback `3.27.7`)
  - `testRuntimeOnly` : `junit-platform-launcher` (fallback `1.14.3`)
  - `workspace-bom` platform sur `testImplementation` + `testRuntimeOnly`

* `CucumberConventionsPlugin` (via `TestDependencies.addCucumberDeps`) :
  - `testImplementation` : `cucumber-java`, `cucumber-junit-platform-engine`,
    `cucumber-picocontainer` (fallback `7.34.3`), `junit-platform-suite` (fallback `1.14.3`)
  - `workspace-bom` platform
  - `addFromCatalog` pattern existant (lit catalogue local, fallback hardcoded)

* Helper DDD `TestDependencies.kt` (single responsibility = gestion deps test) :
  - `addCucumberDeps`, `addJunitDeps`, `addPlatformBom`, `addFromCatalog`, `libs`
  - Constantes `CUCUMBER_FALLBACKS`, `JUNIT_FALLBACKS`, `WORKSPACE_BOM_COORDINATES`
  - Consommateurs : CucumberConventionsPlugin, GradlePluginConventionsPlugin, FunctionalTestConventionsPlugin (refactor)
