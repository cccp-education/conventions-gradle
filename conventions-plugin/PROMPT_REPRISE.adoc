== Règles dures

* **Ordre DAG** : N0 → N1 → N2 → consommateurs. Un consommateur ne peut pas
  résoudre une version non taggée.
* **Un artefact = un canal = un nom = une version.** Aucun `libs.versions.toml`
  publié ne référence `education.cccp:<x>` (grep final = 0).
* Local = Build, Tests = CI. Ne pas lancer de tests locaux.
* **Ne pas toucher** `foundry/private/**` ni `office/**`.
* Pas de `git tag`/`push` sans preuve de compilation (Local = Build) ; tag
  annoté `vX.Y.Z`, version bumpée **avant** le tag.
* Rollback conservé : `CCCP_PUBLISH_TARGET=central|portal` (global, jamais
  par artefact).
